### 1. Day-to-Day File Changes

You only ever touch these files moving forward:

* **In `Automation Labs Config/` (Pushing Configs):**
* `inventory/hosts.yaml` — Add or modify switch IPs, hostnames, and SSH credentials.
* `templates/router_base.j2` — Adjust Jinja2 templates (Syslog, NetFlow, SNMP, ACLs, Interfaces).
* `deploy_configs.py` — Run this script to generate `.cfg` files and push them to your Cisco devices over SSH.


* **In `Network Observability Config/targets/` (Receiving Metrics):**
* `targets/cisco.yml` — Add the switch IP here so SNMP Exporter can poll CPU, memory, and interface metrics.
* `targets/icmp.yml` — Add the switch IP here so Blackbox Exporter continuously pings it for up/down latency tracking.
* `targets/tcp.yml` — Add IP:Port pairs (e.g., `192.168.1.1:22`) to check if SSH or other ports are responsive.
